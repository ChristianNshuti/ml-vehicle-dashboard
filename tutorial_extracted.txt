Machine Learning: Advanced Vehicle Management Dashboard 
This tutorial guides you to building a styled Django dashboard that displays grouped data and charts. 
PART 1: Create Virtual Environment 
1. Create project folder: 
mkdir vehicle_ml_dashboard cd vehicle_ml_dashboard 
2. Create virtual environment: 
python -m venv venv 
3. Activate virtual environment: 
Windows: venv\Scripts\activate 
Mac/Linux: source venv/bin/activate 
Using requirements.txt (Recommended Method) 
To generate requirements.txt automatically: 
pip freeze > requirements.txt 
Open it and Add below packages in requirements.txt file: 
django pandas plotly 
Then install all packages at once: 
pip install -r requirements.txt 
PART 2: Create Django Project and App 
Create project and app: 
django-admin startproject config . python manage.py startapp vehicles 
 
 
 
PART 3: Add 'vehicles' to INSTALLED_APPS in settings.py. 
INSTALLED_APPS = [

import pandas as pd  def frequency_table(df): 
    # Simple counts 
    manufacturer_counts = df['manufacturer'].value_counts().reset_index() 
    manufacturer_counts.columns = ['Manufacturer', 'Count'] 
     
    # Convert to HTML using the correct method name: .to_html() 
    table_html = manufacturer_counts.to_html( 
        classes="table table-bordered table-striped table-sm",  
        float_format='%.2f', 
        justify='center' 
    ) 
    return table_html 
 
PART 6:  Within vehicle app/folder, add below code in views.py 
 
import pandas as pd 
from django.shortcuts import render 
from .dashboard import frequency_table 
 
def dashboard_view(request): 
    queryset = pd.read_csv("dummy_data/vehicles_data_1000.csv") 
    df = pd.DataFrame(queryset) 
 
    return render(request, "vehicles/index.html", { 
        "frequency_table": frequency_table(df) 
    })

PART 8: URL Configuration 
Create urls.py within vehicles app/folder and add below code # vehicles/urls.py from django.urls import path 
from .views import dashboard_view 
 
urlpatterns = [ 
    path("", dashboard_view, name="dashboard"), 
]  
Add below code in urls.py found in config folder # config/urls.py from django.urls import path, include 
 
urlpatterns = [ 
    path("", include("vehicles.urls")), 
]
